Nesta atividade, foi feito em seis etapas, e tem mais a segunda parte onde tivemos que implementar uma pagina de login

cadastro_usuario.php: criado para cadastrar um usuário novo no sistema

cadastro_tarefa.php: foi criado para cadastrar uma tarefa nova, colocando o responsável por ela, a descrição dela, 
em qual parte do processo ela está e qual o nível de prioridade

db.php: foi criado para fazer a ligação com o bnco de dados

gerenciar_tarefas.php: foi criado para editar as tarefas, podendo mudar quem é o responsável, a descrição, a 
prioridade e o setor onde ela está sendo trabalhada

index.php: criado para fazer o design do site

login.php: usado para fazer a tela de login do site

style.css: usado para estilizar o site
